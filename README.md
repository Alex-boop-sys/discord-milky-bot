# Milky — тематический Discord-бот

Любительский чат-бот для Discord: отвечает от лица персонажа Милки (через несколько
ИИ-провайдеров с резервными моделями), ищет арты, генерирует картинки, ведёт
статистику общения и небольшую «экономику» Геофруктов за бампы сервера.

Проект для личного пользования небольшой компанией. Статус: в разработке.

## Что умеет

**Общение.** Милки отвечает, если к ней обратиться по имени («Милки, привет»),
упомянуть через `@` или ответить на её сообщение. Контекст помнится отдельно
для каждого человека (последние 10 записей), но общий для всех серверов.

Не чаще одного обращения (общение, арты, генерация) за 5 секунд от одного человека —
таймер задаётся в `config.py` (`user_cooldown_seconds`).

**Чего бот не отвечает.** Если запрос начинается со знака из `ignored_prefixes` в `config.py`
(`! . / - ; :`) и сразу за ним идёт буква или цифра, Милки молчит: это похоже на команду
другого бота (`!play песня`, `.r d20`, `/help`). Обычный текст не страдает: «Милки: привет»,
«Милки - привет», «...ну ладно», «:)» отвечаются как обычно. Сообщение, начинающееся с `\`,
игнорируется всегда: так можно ответить на сообщение Милки, не вызывая ответ.

**Слово-команды в обращении:**

| Что написать | Что будет |
|---|---|
| `Милки, арт лиса` | поиск арта на e621 по тегам |
| `Милки, сгенерируй закат над морем` | генерация картинки |
| `Милки, создай картинку про осень` | то же самое |

**Слэш-команды:**

| Команда | Что делает |
|---|---|
| `/забыть` | удаляет вашу историю диалога с ботом (статистика сохраняется) |
| `/арт [теги]` | поиск арта на e621 |
| `/фурь [теги]` | поиск SFW-артов на Furbooru |
| `/стат` | топ-10 по обращениям к боту (общий для всех серверов; людей не с этого сервера бот подписывает «Пользователь скрыт») |
| `/баланс` | сколько у вас Геофруктов 🫐 |
| `/топ-бамперов` | топ-10 по Геофруктам |

`/баланс` и `/топ-бамперов` работают только на серверах с экономикой, на остальных
бот отвечает «Это пока не работает тут».

NSFW-арты доступны только в каналах с возрастным ограничением. В обычных каналах и в
личных сообщениях бот всегда ищет только рейтинг `safe`.

## Установка и запуск

Нужен **Python 3.10 или новее**.

```bash
pip install -r requirements.txt
```

1. Скопируйте `.env.example` в `.env` и заполните его (см. ниже).
2. Включите в [портале разработчиков Discord](https://discord.com/developers/applications)
   для бота **Message Content Intent** и **Server Members Intent**.
3. Запустите:

```bash
python main.py
```

### Настройки в `.env`

| Переменная | Обязательна | Для чего |
|---|---|---|
| `DISCORD_TOKEN` | да | токен бота |
| `GROQ_API_KEY`, `OPENROUTER_API_KEY`, `ZAI_API_KEY` | да | ключи ИИ-провайдеров |
| `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | да | доступ к Cloudflare Workers AI |
| `OWNER_ID`, `CO_OWNER_ID` | нет | Discord ID владельцев для административных команд `root#` |
| `MAIN_GUILD_ID` | нет | ID основного сервера (под ним хранится общий баланс) |
| `ALLOWED_GUILD_IDS` | нет | серверы, где бот работает (через запятую). Пусто — только основной |
| `ECONOMY_GUILD_IDS` | нет | серверы с экономикой Геофруктов. Пусто — только основной |
| `GREETINGS_CHANNEL_IDS` | нет | каналы утреннего приветствия. Пусто — приветствий нет |

**Файл `.env` никому не показывайте и не добавляйте в git** — он уже в `.gitignore`.
Если токен случайно попал в репозиторий, сразу сбросьте его в портале разработчиков
(Bot → Reset Token).

## Несколько серверов

Все ID серверов и каналов хранятся только в `.env`, в коде их нет. Бот работает
только на серверах из `ALLOWED_GUILD_IDS` (если список пуст — только на `MAIN_GUILD_ID`;
если не задано ничего, ограничений нет). Если его добавят на любой другой сервер, он
сразу выйдет; то же произойдёт при запуске, если бота добавили, пока он был выключен.

**Как добавить новый сервер:**

1. Узнайте ID сервера: в Discord включите «Режим разработчика» (Настройки →
   Расширенные), затем ПКМ по серверу → «Копировать ID сервера».
2. Впишите ID в `ALLOWED_GUILD_IDS` в `.env` (через запятую, например `111,222`).
3. Если нужны утренние приветствия — добавьте ID канала в `GREETINGS_CHANNEL_IDS`,
   если нужна экономика Геофруктов — ID сервера в `ECONOMY_GUILD_IDS`.
4. Перезапустите бота и только после этого пригласите его на сервер.

Если в ID закралась опечатка (буква, пробел внутри числа), бот при запуске остановится
и скажет, в какой переменной ошибка.

**Что общее для всех серверов:** история диалогов с каждым человеком, статистика `/стат`,
баланс Геофруктов. **Что настраивается отдельно:** NSFW-режим (по каналу), размер файлов
(по уровню буста сервера). В логах каждая строка помечена сервером и каналом:
`[Мой сервер #общий] Ответ на сообщение ...`.

Утреннее приветствие отправляется в одно время и одним и тем же текстом во все
каналы из списка. Если в каком-то канале отправить не удалось (удалён, нет прав),
остальные всё равно получат приветствие.

## Тесты

Тесты — это маленькие программы, которые сами проверяют, что код работает как задумано,
и сразу показывают, если после правки что-то сломалось. Подключаться к Discord для
этого не нужно.

```bash
pip install -r requirements-dev.txt
python -m pytest
```

В конце будет что-то вроде `239 passed` — всё хорошо. Если видите `failed`, pytest
покажет, какая проверка не прошла и почему. Запускайте тесты после каждой заметной
правки. Они работают на временных базах и не трогают настоящие данные бота.

Что проверяется (папка `tests/`):

| Файл | Что проверяет |
|---|---|
| `test_dicts.py` | все ключи, которые использует код, есть в `dicts.json` (ловит опечатки) |
| `test_triggers.py` | распознавание «арт» / «сгенерируй» и отсутствие ложных срабатываний |
| `test_nsfw.py` | NSFW-фильтры, невозможность обойти SFW-режим своим `rating:`-тегом |
| `test_history.py` | история диалогов, лимит записей, `/забыть`, статистика |
| `test_economy.py` | начисление Геофруктов, защита от двойной выдачи |
| `test_trim_text.py` | обрезка оборванных ответов ИИ |
| `test_message_flow.py` | весь путь обращения: имя, `@`, ответ на сообщение; чужие команды; пустые обращения; игнор-лист |
| `test_bot_setup.py` | сборка бота, запрет пинга `@everyone`, триггеры, таймер во всех способах обращения, чужие серверы |
| `test_cooldown.py` | таймер между обращениями (время подставляется вручную) |
| `test_guilds.py` | список разрешённых серверов, выход с чужих |
| `test_morning_greetings.py` | рассылка приветствий по нескольким каналам |
| `test_logging_place.py` | сервер и канал в строках лога |
| `test_config_lists.py` | разбор списков ID из `.env` |
| `test_config_structure.py` | структура проекта и корректность JSON |

Добавляя новую функцию, добавьте к ней тест: самый простой образец — `tests/test_triggers.py`.

## Структура проекта

```
main.py                 запуск бота
config.py               настройки, пути, переменные из .env
requirements.txt        зависимости бота
requirements-dev.txt    зависимости для тестов
resources/
  dicts.json            реплики, промпт, списки слов
  ignored_users.json    пользователи, которых бот игнорирует
src/
  bot/                  сборка бота, слэш-команды, обработчики событий
    handlers/           сообщения, события экономики, выход с чужих серверов
  features/             арты, генерация картинок, экономика, утренние приветствия
  services/
    ai.py               запросы к ИИ-провайдерам
    history.py          история диалогов и статистика (SQLite)
  utils/                логгер, загрузка JSON, триггеры, таймер между обращениями
tests/                  автоматические тесты (helpers.py — общие подделки Discord)
data/                   базы и состояние (создаётся при запуске, не в git)
logs/                   логи (создаётся при запуске, не в git)
```

## База данных

История и статистика хранятся в `data/history.db`. Формат версии 2: таблица `history`
(контекст для ИИ, хранится только последние записи) и `user_stats` (счётчик
обращений, который только растёт). Если бот при запуске пишет, что база имеет старый
формат, её нужно один раз перенести разовым скриптом миграции.
